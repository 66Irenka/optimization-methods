# Lab 1 — Методи оптимізації нульового порядку

## Завдання

- Побудувати графік заданої функції однієї змінної та її першої похідної.
- Знайти точку екстремуму методами:
  - дихотомії;
  - золотого перетину;
  - Фібоначчі.
- Порівняти ефективність методів за кількістю ітерацій.
- Обчислити першу та другу похідні у точці екстремуму.
- Перевірити необхідні та достатні умови оптимальності.
- Побудувати 3D-графік функції двох змінних та її лінії рівня.
- Знайти екстремум методом координатного спуску.

# Lab 2 — Методи оптимізації першого порядку

## Завдання

- Побудувати 3D-графік функції двох змінних та її лінії рівня.
- Знайти стаціонарну точку функції.
- Перевірити умови існування мінімуму за допомогою матриці Гессе.
- Реалізувати методи оптимізації першого порядку:
  - градієнтний спуск;
  - найшвидший спуск;
  - метод Флетчера–Рівса.
- Знайти точку мінімуму функції та значення функції в точці екстремуму.
- Порівняти ефективність методів за кількістю ітерацій.
- Провести аналіз збіжності отриманих результатів.

## Завдання
